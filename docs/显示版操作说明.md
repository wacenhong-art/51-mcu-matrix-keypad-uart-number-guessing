# 实验一：液晶与数码管显示版

在原有矩阵键盘猜数字、中文串口输出的基础上，按用户要求增加 LCD1602 提示和八位数码管显示。原串口版工程保留在 experiment1 目录，本目录为新增显示版。

## 操作与显示

1. 上电后，LCD 第一行 `GUESS 0000-9999`，第二行 `K3:START K4:OK`；数码管显示八条横杠。
2. 按 K3 开始。LCD 显示 `IN:____ K4:OK`，等待四位数字。
3. 矩阵 S1～S10 对应数字0～9。每次按下并松开一个键，LCD 与数码管左四位同步显示输入；未填位置为下划线/横杠。S11～S16无效。
4. 输入四位后按 K4。LCD 第一行 `LAST:0123` 一类内容保留上次猜测，第二行 `X:2 Y:1 NEXT:KEY` 显示结果。数码管左四位保留输入，右四位显示 `-2-1`。
5. X 是数字正确总数（包含位置也正确者），Y 是位置正确数。重复数字按出现次数匹配，不重复计数。
6. 猜错后直接输入下一组四位数字即可，不必再按 K3。上次 X/Y 保留供参考；按 K3 则重新生成目标，开始新局。
7. 猜对时 LCD 显示 `ALL CORRECT!`、`K3:NEW GAME`，数码管右四位显示 `PASS`，左四位保留猜中的数字。按 K3 开新局。
8. 少于四位就按 K4，LCD 提示 `NEED 4 DIGITS`，继续补足即可。

不按 K1、K2，以免干扰串口。目标数不会在屏幕上提前公布。LCD1602使用其内置字符显示英文提示，串口仍输出中文。

## 硬件与驱动

- LCD1602：P0 数据总线；RS=P2.6，RW=P2.5，E=P2.7，依据普中 `25-LCD1602液晶显示实验.zip`。
- 数码管：P0段码；P2.2/P2.3/P2.4控制74HC138位选，111为最左位，依据普中 `7-动态数码管实验.zip`。
- 共用P0的处理：LCD的E平时为低，数码管扫描不触发LCD写入。写LCD时仅在短暂的总线操作期间关闭中断，E脉冲结束立即恢复当前数码管段码；LCD命令等待期间恢复中断，继续扫描数码管。
- Timer2以FC66自动重装，11.0592MHz/12下约1ms扫描一位，八位刷新约125Hz。Timer0仍自由计数用于随机种子，Timer1仍产生9600串口波特率。
- 不整口覆盖LCD控制引脚来选择数码管位，保留P2其他位。液晶采用上电等待和重复0x38初始化。

照片中液晶背光亮、第一行黑块通常表示尚未正常初始化；是否已解决需以新版烧录后的实际显示为准。若字符过淡，可轻调液晶对比度电位器；若仍是方块，应先核对模块插接与实际显示反馈。

## 构建与下载

打开 `experiment1.uvproj` 编译，或执行 `build.ps1`。下载文件为 `experiment1.hex`。

实际Keil C51编译/链接：0错误、0警告，code=2658字节，data=56.1字节。

PZ-ISP已完成本版程序写入，日志显示“文件下载完毕”，耗时6.092s；串口已收到 `Guess game LCD+LED v2` 启动信息。LCD及数码管实际显示验收另据用户反馈记录，不能仅以烧录日志证明显示效果。

原版三轮串口实测记录属于旧版固件，本版新增显示需单独验证。

## 本版实际验证

用户实际按K3、输入0123、按K4后，COM7接收“2个数字正确，1个位置正确”，用户同时确认LCD显示 `LAST:0123`、`X:2 Y:1 NEXT;KEY`。液晶输入与比较结果已实物验证；用户进一步确认数码管实际显示 `0123-2-1`；LCD、数码管和串口结果一致。采集后已停止串口监视并释放COM7，开发板可独立操作。
